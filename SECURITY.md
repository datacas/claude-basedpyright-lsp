# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/datacas/claude-basedpyright-lsp/security/advisories/new).

You can expect an initial response within 7 days. Once the issue is confirmed, a fix
and a new release follow as soon as possible, and you will be credited in the
advisory unless you prefer otherwise.

## Scope

This repository only contains the plugin manifests that tell Claude Code how to start
`basedpyright-langserver`. Vulnerabilities in BasedPyright itself should be reported
to the [BasedPyright project](https://github.com/DetachHead/basedpyright/security),
and vulnerabilities in Claude Code to
[Anthropic](https://www.anthropic.com/responsible-disclosure-policy).
